# 実装計画：要約長の再調整と背景デザイン更新

「その他のニュース」の要約を150文字に増やし、Webとメール双方に反映させます。また、背景デザインのバリエーションを提案し、指定された雰囲気に調整します。

## ユーザーレビューが必要な項目

### 背景デザインの提案パターン
背景の色合いについて、以下の4つのパターンを検討しました。

1. **Pattern A: Aurora Mint (現在の進化形)**
   - **色合い**: 極めて淡いミントグリーンとソフトピンクの融合。
   - **印象**: 明るく清潔感があり、最新のAIツールのような軽やかな印象。

2. **Pattern B: Deep Midnight (テック・ダーク)**
   - **色合い**: 深いネイビー (#0f172a) から紫へのグラデーション。
   - **印象**: 高級感と重厚感があり、夜間の確認でも目が疲れにくいテック志向のスタイル。

3. **Pattern C: Soft Slate (モダン・ナチュラル)**
   - **色合い**: 落ち着いたブルーグレー (#f1f5f9) と淡いブルー。
   - **印象**: 知的で落ち着きがあり、長時間の読解に適した新聞のような安心感。

4. **Pattern D: Neon Nebula (近未来ビビット)**
   - **色合い**: 鮮やかなバイオレットとブルーの動的なグラデーション。
   - **印象**: 非常にダイナミックで「AIによる選別」という先進性を強く感じさせるスタイル。

> [!IMPORTANT]
> 特にご希望がなければ、**Pattern C (Soft Slate)** をベースに、現在の清潔感を維持しつつ色合いに深みを持たせる調整を行います。他のパターンが良い場合はお知らせください。

## 提出される変更

### [Backend] 要約文字数の変更
- `ai_processor.js` のプロンプトにて、`otherNews` の要約文字数を 100文字 → 150文字 に修正。

### [Frontend] 背景デザインの更新
- `style.css` の `body` 背景色およびグラデーション変数を調整。
- 階層感を出すため、パネルの影やボーダーの透過率を微調整。

---

## 検証プラン
- `node backend/index.js --run-now` で生成されるJSONの文字数が指定通りになっているか確認。
- ブラウザ上の「その他のニュース」が見やすくなっているか、背景が新しい色合いになっているか確認。
