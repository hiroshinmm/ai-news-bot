# AIニュース生成におけるJSONパースエラーの修正

GitHub Actionsでの実行時に発生した、AI（Gemini）からのレスポンスのパースエラーを修正します。主な原因は、大量のニュース記事に対して長い要約を要求したことによる、レスポンスの途切れ（トークン上限超過）と考えられます。

## ユーザーレビューが必要な項目

> [!IMPORTANT]
> 要約文字数を維持するため、50件のニュースを**2回に分けてAIに処理させる「分割処理」**を導入します。これにより、1回のレスポンス量を抑えつつ、指示通りのボリュームを確保します。

## 提案される変更

### Backend Component

`backend/ai_processor.js` におにおいて、以下のロジック変更を行います。

#### [MODIFY] [ai_processor.js](file:///c:/Users/hiros/OneDrive/デスクトップ/Antigravity/AI%20News/backend/ai_processor.js)

- **分割処理の導入**:
    - 50件の全ニュースを一度に渡すのではなく、以下の2ステップで処理します。
        1. **ステップ1**: 全リストから「ヘッドライン3件」と「次点10件」を選別・要約し、残りのインデックスを取得。
        2. **ステップ2**: 残りの37件を「その他のニュース」として要約。
- **プロンプトの調整**:
    - 「文字数を減らす」指示は行わず、指示された200文字/150文字を維持します。
- **JSONモードの有効化**:
    - Gemini SDKの `responseMimeType: 'application/json'` を追加し、出力の堅牢性を高めます。
- **maxOutputTokens の明示設定**:
    - 出力の上限トークン数を明示的に大きく設定（例: 8192）します。

## 検証プラン

### 自動テスト
- `node backend/ai_processor.js` を直接実行し、分割処理が正常に走り、最終的に1つのJSONに統合されることを確認します。

### 手動確認
- 生成された `data/latest_news.json` の中身を確認し、すべての記事が正しく要約され、末尾までデータが含まれているかチェックします。
