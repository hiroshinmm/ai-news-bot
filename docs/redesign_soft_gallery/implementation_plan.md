# AIニュース自動収集・要約ツール 実装計画: Soft Gallery (B-3) 刷新

## 概要
現在のダークモードから、明るく清潔感のある「Soft Gallery」デザイン（コンセプトB-3）へ刷新し、さらに利便性を高めるために全ニュース記事の要約機能を追加します。

## 主な変更点

### 1. デザインの刷新 (Soft Gallery B-3)
- **配色**: 白背景 (#f8fafc) を基調に、セージグリーン (#e8fdf5) とスモーキーピンク (#fde8e8) をアクセントに採用。
- **タイポグラフィ**: モダンで親しみやすい 「Outfit」 をメインに、本文は 「Inter」 を使用。
- **レイアウト**: 24px의 大きな角丸と柔らかい影を多用し、各記事をギャラリーの作品のように配置。

### 2. 全ニュース記事のAI要約
- **バックエンド**: `ai_processor.js` のプロンプトを更新し、取得した全記事（約50件）に対して要約を作成。
- **データ階層**: ニュースを「ヘッドライン (3件)」「注目のニュース (10件)」「その他のニュース」に分類し、全てに要約を付与。

### 3. モバイル・メール対応
- **モバイル**: 長いタイトルが折り返されるようフレキシブルなレイアウトを維持。
- **メール**: 送信されるHTMLメールにも、全件要約が含まれるように `mailer.js` を更新。

## 検証項目
- ローカル環境での表示確認（`npm run dev`）。
- GitHub Actionsによる自動実行とPagesへのデプロイ。
- 受信メール内の要約表示確認。
